# Roadmap

**As of:** November 2, 2026

| Stage | Intended outcome | Current state |
|---|---|---|
| Foundation | Public specification, research, plan and OSS repository | Documentation stage |
| Workflow proof | One demonstrated Comfy audio-conditioned world and measured resources | Planned; no generation run |
| First useful tool | Comfy App Mode: one excerpt, image, world, review and honest export | Planned; no app code |
| Creative depth | Three worlds, loop finishing, portrait and comparative takes | Proposed |
| Broader studio | Optional own-agent MCP companion, richer interface, longer arrangements and Comfy music generation | Exploratory |
| Commercial options | Possibly managed compute, teams, support or a paid edition | Unselected; no offer or pricing |

The long-term direction is a musician-directed visual studio with portable Comfy recipes. [PLAN.md](PLAN.md) owns the immediate sequence and proof gates. The [issue tracker](https://github.com/Zuberverse/soundscape-studio/issues) owns actionable work; this table is not a second backlog.
