# Contributing

Soundscape Studio is currently a specification and research foundation. Useful
contributions include correcting primary-source evidence, clarifying the user
journey and documenting a reproducible Comfy capability investigation.

Check the [issues](https://github.com/Zuberverse/soundscape-studio/issues) before
starting work. Discuss large changes first. Keep pull requests scoped and name
what changed, why, how it was checked and what remains unverified. Never commit
credentials, account data, private input media or model weights.

All media generation must use Comfy workflows. Identify partner/API nodes,
backend/model versions, costs and licenses in any evidence you contribute.
Only share media you have permission to publish. A documented generation
failure is useful evidence; do not disguise an alternate pipeline as a success.

Original contributions are provided under the repository's MIT License unless
a different arrangement is explicitly agreed. Retain necessary third-party
notices. No contributor license agreement or exclusive relicensing grant is
requested by this foundation.

For documentation, check links, facts, status wording and `git diff --check`.
For future code, follow the tested commands recorded in docs/DEVELOPMENT.md.
