# Security

This repository has no runnable application or hosted service yet. No security
assessment of an executable product is claimed.

Do not place credentials, private media, signed URLs or account diagnostics in
issues or pull requests. For a sensitive vulnerability, use GitHub's private
vulnerability reporting option when available; otherwise contact the maintainer
through the public profile to arrange a private channel before sharing details.

Future implementation must keep provider credentials on the service side,
validate uploaded media and paths, isolate local project files and recover jobs
without accidental duplicate paid submissions. See docs/ARCHITECTURE.md.
